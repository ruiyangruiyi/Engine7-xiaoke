# 日杂风/MUJI风格家装设计调研

> 为「栖」视觉风格设计搜集，调研员产出

---

## 调研总结

日杂风（Japanese Minimalist / MUJI Style）的核心是"简素、自然、温润"。2024-2025趋势从冷调极简回归暖调舒适，强调材质触感与光线流动。整体氛围追求"可以呼吸的家"——不是空洞的留白，而是因收纳有序、动线清晰而呈现的从容感。

## 设计参考方向（5个）

### 1. 配色：奶油暖白 + 浅原木为主调
- 基底色：纯白/奶油白（orchid white, sail white）
- 主色：浅木色地板与家具（檜木、杉木、桦木色调）
- 点缀色：奶茶色、暖灰、豆沙绿——对比极弱、柔和不抢眼
- 原则：全屋配色不超过3种（黑白不计），同色系深浅渐变增加层次

### 2. 材质：天然原木 + 棉麻布艺 + 哑光面
- 木材为主角：原木家具、木地板、木天花板延伸统一感
- 软装：棉麻沙发与坐垫、藤编/和纸元素点缀
- 表面处理：全哑光，拒绝亮面反光，保留材质原始肌理
- 避免金属感，色调统一于木质暖调

### 3. 排版与空间：克制留白 + 中文日文混排
- 留白是设计语言：画面/空间大面积留白，信息密度低
- 文字风格：细体明体/宋体，行距宽裕，字号小而精致
- 中日混排：竖排或小段日文假名/汉字点缀，传递"日杂"气质
- 辅助元素：细线分隔、圆形标记、手写感标注

### 4. 空间气质：禅意 + 温馨并存
- 非冷冰冰的极简，而是"温暖的简"——比北欧风更柔和、更有人情味
- 低矮家具降低视觉重心，营造安稳感
- 收纳哲学："断舍离"，杂物隐于地台/隐藏柜，视觉极净

### 5. 光线：自然光优先 + 柔和间接照明
- 大量自然光自由流动，窗帘用透光棉麻
- 间接照明为主：灯带、地脚灯、暖光台灯（3000K暖白）
- 避免直射强光，营造黄昏般温柔的室内光环境
