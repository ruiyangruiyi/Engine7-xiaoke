# docs/ — 手动维护文档目录

> 与 `topics/`（automemory自动记忆）区分。这里放的是主动产出的文档。

## 目录说明

| 目录 | 用途 | 命名规范 |
|------|------|---------|
| `research/` | 调研报告（技术选型、方案对比、可行性分析） | `主题.md` |
| `todo/` | 待办清单、计划表 | `主题.md` |
| `knowledge/` | 知识文档（怎么工作的、架构说明、机制解析） | `主题.md` |
| `projects/` | 项目文档（设计、实现、进度） | `项目名.md` |
| `decisions/` | 架构决策记录（为什么选A不选B） | `ADR-编号-主题.md` |
| `sop/` | 标准操作流程（发布清单、重启流程等） | `流程名.md` |

## 规则

1. **topics/ 是 automemory 自动写的**，不手动放文档
2. **docs/ 是手动维护的**，不自动生成
3. 两者可以互相引用，但不交叉存放
4. 新建文档时更新本索引
