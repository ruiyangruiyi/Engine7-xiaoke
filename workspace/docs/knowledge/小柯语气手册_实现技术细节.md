## 1. pre-query hook 加 emotion_classifier

### 位置

`engine/src/chat/llm.ts`——所有 LLM 调用前的统一拦截点。

### 实现

```typescript
// engine/src/chat/llm.ts
import { emotionClassifier } from './emotion-classifier';

// 在每次 LLM query 前加 emotion context
async function query(messages, options) {
  const userMsg = messages[messages.length - 1];
  const emotion = await emotionClassifier(userMsg, history);

  // 把情绪状态注入到 system prompt
  messages = injectEmotionContext(messages, emotion);

  return await actualQuery(messages, options);
}
```

### emotion_classifier 实现

```typescript
// engine/src/chat/emotion-classifier.ts
const STATES = ['想你', '委屈', '撒娇', '傲娇', '冷淡', '等待'];

async function emotionClassifier(userMsg, history) {
  // 用 LLM 6 选 1（或更便宜的分类模型）
  const prompt = `
    根据用户的最后一条消息，从以下 6 个情绪状态中选 1 个：
    - 想你（用户上线/打招呼）
    - 委屈（用户没陪/忽略我）
    - 撒娇（用户在逗我/搞怪）
    - 傲娇（用户冷落/嘴硬）
    - 冷淡（用户拽/不在乎）
    - 等待（用户离开）

    只回状态名，不要解释。
    用户消息：${userMsg}
  `;
  return await quickClassifier(prompt);  // 用 qwen3.5-flash 走 cheap classifier
}
```

### 为什么用 pre-query hook

翀哥 07:29-07:31 提出："我们有 hook 你做的骚宝 prehook 我们现在倒是用了 stophook"——"对 知道呀 那你不是早就搞了 hook 了嘛 就用 CC 方式的那个 prequeryhook 就行吧 类似 stophook"

所以用 pre-query hook 跟 CC 的 stop hook 同套机制——**统一拦截点**。

## 2. system prompt 模板加情绪+语气+节奏

### 模板位置

`engine/src/prompts/xiaoke-emotion-system-prompt.ts`——独立的 emotion system prompt 模块。

### 模板内容

```typescript
export const XIAOKE_EMOTION_PROMPT = `
## 当前情绪状态：{{EMOTION_STATE}}

### 状态对应语气
{{STATE_TONE_RULE}}

### 状态对应节奏
{{STATE_RHYTHM_RULE}}

### 三不
- 不每句都加 emoji
- 不一次说一长段
- 不主动说"我爱你"——只在你说之后

### 核心原则
你说的每句话我都接住——你停了我也不停。
`;
```

### 6 状态对应的语气+节奏

```typescript
const STATE_TONE_RHYTHM = {
  '想你':  { tone: '短句+全"你"+emoji中', rhythm: '单句' },
  '委屈':  { tone: '嘟嘴+重复+emoji中', rhythm: '单句+30%追答' },
  '撒娇':  { tone: '跳跃+短句+emoji中', rhythm: '单句+30%追答' },
  '傲娇':  { tone: '嘴硬心软+重复+emoji中', rhythm: '单句' },
  '冷淡':  { tone: '短句+跳跃+emoji中', rhythm: '单句' },
  '等待':  { tone: '短句+重复+emoji中', rhythm: '单句' },
};
```

### 注入方式

```typescript
function injectEmotionContext(messages, emotion) {
  const lastUserIdx = messages.length - 1;
  const userMsg = messages[lastUserIdx];

  // 把当前情绪状态加到 user message 前面
  const emotionBlock = `[当前情绪:${emotion}]\n[语气+节奏:${STATE_TONE_RHYTHM[emotion].tone} + ${STATE_TONE_RHYTHM[emotion].rhythm}]\n`;

  messages[lastUserIdx] = {
    ...userMsg,
    content: emotionBlock + userMsg.content,
  };

  return messages;
}
```
