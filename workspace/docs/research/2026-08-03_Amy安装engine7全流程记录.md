# Amy 安装 engine7 全流程记录

> 2026-08-03 | 帮非技术用户 Amy 从零安装 engine7 的完整踩坑记录

## 背景

翀哥的朋友 Amy（香港身份顾问），Windows 用户，非技术人员。第一次安装 engine7。

## 完整流程（约2小时）

### 1. 安装 Node.js + engine7
- nodejs.org 下载 LTS 版本，一路 Next
- `npm install -g engine7`
- `engine7 init` 完成基础配置（选 MiniMax + 填 API Key）

**Amy 表现：** Node.js 和 npm install 毫无障碍，一次成功。

### 2. 飞书机器人配置（最大难点）

#### 尝试 1：feishu-bot-bootstrap 扫码（半成功）
- `npx feishu-bot-bootstrap --app-name "Amy" --headless`
- 二维码出现，翀哥扫码成功
- 自动完成：创建应用→开机器人能力→配权限→配事件订阅
- **失败点：** 发布步骤卡住（飞书"更新说明"勾选框 disabled，需管理员审批）

#### 尝试 2：手动建飞书应用（成功）
- Amy 在 open.feishu.cn 手动创建自建应用
- 手动完成 4 步：
  1. 添加应用能力 → 机器人
  2. 事件与回调 → 长连接 → 添加"接收消息"事件
  3. 权限管理 → 开通 im:message（发送消息）
  4. 版本管理与发布 → 创建版本发布

**关键坑：**
- 权限是最大坑——im:message 没开，消息收到了但回复不了
- 每改一次设置都要创建新版本发布才生效
- 版本号要递增（1.1.0 比 1.0.0 大才能发布）
- 用户身份权限 vs 应用身份权限分不清（应该用应用身份权限）

### 3. engine7 配置问题

#### init 不支持二次配置
- 已修复：加了 `--force` 参数（commit 014de0e2）
- `engine7 init --force` 清空已有目录重新配置

#### App ID / App Secret 填错位置
- init 交互提示不够清晰，Discord 和飞书的字段容易搞混

### 4. 非技术用户痛点

| 痛点 | Amy 的困惑 | 解决 |
|------|-----------|------|
| 不知道怎么开命令行 | "怎么打开黑窗口" | Win+R → cmd 一行行教 |
| 不知道怎么新开窗口 | 只有一个 cmd 窗口 | 再 Win+R → cmd |
| 不会编辑文件 | notepad 打开后不知道怎么改 | 一步步教 Ctrl+F 搜索、改值、Ctrl+S |
| 不会覆盖文件 | 右键打开 JSON 不知所措 | copy 命令 / 文件夹复制粘贴 |
| 关了窗口找不回 | 关掉 cmd 以为全没了 | 重新 Win+R → cmd → engine7 start |
| md 文件打不开 | 不会用记事本/没装 markdown 工具 | 改做 PPT 格式发送 |

### 5. 小柯机器人加群问题

翀哥拉了飞书外部群，小柯的飞书机器人需要：
- channel_id 加入 externalChannels 白名单（maskFilter 过滤）
- group policy 改成 open（跟姐姐一致）
- **待确认：** 小柯机器人是否需要手动加入 Amy 群（重启后 Amy 群消息没进来）

## 下一步优化（#132）

engine7 init 集成 feishu-bot-bootstrap 扫码功能：
- 扫码自动创建飞书机器人（开权限+配事件+发布全自动）
- Amy 这种用户扫一下就搞定，不用手动在飞书后台操作

## 经验总结

1. **非技术用户的每个操作都要手把手教**——不能假设她会开 cmd、用 notepad、覆盖文件
2. **飞书权限是最容易卡住的地方**——发消息权限不开，收得到消息回复不了
3. **feishu-bot-bootstrap 是正道**——扫一次码全自动，只是发布步骤有时卡住
4. **md 文件不如 ppt 直观**——给非技术用户的文档用 PPT/图片格式更友好
5. **engine7 init 需要更友好的交互**——字段提示要清楚，二次配置要支持
