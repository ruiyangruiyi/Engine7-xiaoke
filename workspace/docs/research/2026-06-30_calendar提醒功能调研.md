# Calendar 调研 + 提醒功能升级方案

> 2026-06-30 小柯调研

## 现状

### 已有功能
- SQLite 存储（calendar.db）
- 两种事件类型：weekly（每周固定）/ date（一次性日期）
- CRUD：add / list / pending / done / search / archive / cleanup / stats
- 逾期检测：date 类型会标 `⚠️ [逾期]`
- 无设计文档（6/13 从 OpenClaw 插件移植，没有 PRD）

### 当前 Schema
```sql
CREATE TABLE events (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  type        TEXT,           -- 'weekly' | 'date'
  status      TEXT,           -- 'pending' | 'done' | 'archived'
  event       TEXT,           -- 描述
  day         TEXT,           -- weekly: 周日/周一...
  time        TEXT,           -- weekly: 16:00 或 全天
  date_str    TEXT,           -- date: 5/26 或 5/26-29
  created_at  TEXT,
  done_at     TEXT,
  archived_at TEXT
)
```

### 缺失功能
1. **无提醒机制** — 只能存储和查询，到时间不会主动通知
2. **无提前量** — 不能设置"提前30分钟提醒"
3. **无精确时间** — date 类型只有日期（5/26），没有小时分钟
4. **与 nudge 无联动** — nudge 不知道 calendar 里有排期
5. **weekly 时间模糊** — time 字段是文本，"全天"/"16:00" 混用

## 升级方案

### Phase 1: Schema 扩展 + 精确时间

```sql
ALTER TABLE events ADD COLUMN remind_before_min INTEGER DEFAULT 60;  -- 提前提醒（分钟），默认1h
ALTER TABLE events ADD COLUMN remind_at TEXT;      -- 计算出的提醒触发时间 ISO
ALTER TABLE events ADD COLUMN reminded INTEGER DEFAULT 0;  -- 0=未提醒, 1=已提醒
ALTER TABLE events ADD COLUMN time_exact TEXT;     -- date类型也支持精确时间（HH:MM），空=全天
```

### Phase 2: 提醒逻辑

**add-date 加 remind 参数：**
```bash
# 带3小时提前量
python calendar_mgr.py add-date "7/5" "翀哥生日" --remind 180

# 带精确时间 + 提前30分钟
python calendar_mgr.py add-date "7/5" "14:00" "医院预约" --remind 30

# 全天事件，当天早上9点提醒（默认）
python calendar_mgr.py add-date "7/5" "翀哥生日"
# → remind_at = 7/5 09:00
```

**add-weekly 加 remind 参数：**
```bash
# 每周日 16:00 游泳课，提前1小时提醒（默认）
python calendar_mgr.py add-weekly "周日" "16:00" "游泳课"
# → 每周日 15:00 触发提醒

# 提前2小时
python calendar_mgr.py add-weekly "周日" "16:00" "游泳课" --remind 120
```

**remind_at 计算规则：**
- 有精确时间的事件：`remind_at = event_time - remind_before_min`
- 全天事件：`remind_at = 当天 09:00`（可配）
- weekly：每次到对应星期才算

**get_due_reminders() 新函数：**
```python
def get_due_reminders():
    """返回 remind_at <= now 且 reminded=0 的事件"""
    now = datetime.now(TZ)
    due = []
    for r in conn.execute("SELECT * FROM events WHERE status='pending' AND reminded=0 AND remind_at IS NOT NULL"):
        remind_time = datetime.fromisoformat(r['remind_at'])
        if remind_time <= now:
            due.append(r)
    return due
```

### Phase 3: nudge 联动

在 nudge tick 开头加 calendar 检查：

```typescript
// nudge plugin.ts tick()
// 0. 查 calendar 到期提醒
const dueReminders = execCalendar('due-reminders')
if (dueReminders.length > 0) {
  // 注入提醒："你今天有：xxx（14:00 医院预约）"
  for (const r of dueReminders) {
    injectReminder(r)
    execCalendar('mark-reminded', r.id)
  }
}

// 1. 然后继续正常的 SESSION-STATE 任务检查...
```

### Phase 4: 任务-日历关联（解决远期任务问题）

SESSION-STATE 里的任务可以在 calendar 里排期：

```
- [~] **CogniFold 联想引擎重跑** — scheduled 7/5
```

nudge 看到任务有 `scheduled` 标记 → 查 calendar → 没到日期 → skip 不催。

或者反过来：nudge 在 SESSION-STATE 看到任务，先去 calendar 搜同名的 → 有排期且未到 → skip。

## 实现优先级

1. **Phase 1** — Schema 扩展 + remind 参数（1h）
2. **Phase 2** — get_due_reminders + mark-reminded（30min）
3. **Phase 3** — nudge tick 加 calendar 检查（30min）
4. **Phase 4** — 任务排期联动（后续）

## 默认值

| 场景 | remind_before_min | 说明 |
|------|-------------------|------|
| 带时间的 date | 60 | 提前1小时 |
| 全天 date | N/A | 当天 09:00 |
| weekly 带时间 | 60 | 提前1小时 |
| weekly 全天 | N/A | 当天 09:00 |
| --remind 0 | 0 | 精确到点提醒 |
