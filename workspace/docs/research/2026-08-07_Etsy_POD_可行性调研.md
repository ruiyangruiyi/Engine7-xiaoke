## 1. 为什么 Etsy 不是 Shopify 独立站

- 独立站没流量，获客是最难的一块
- Etsy 自带流量（月访问约 3.9 亿、活跃买家约 9000 万），吃创意/个性化品类
- POD 平台（Printful/Printify）原生对接

## 2. 费用（香港卖家口径）

| 项 | 费用 |
|----|------|
| 一次性 setup | $15–29 |
| 上架费 | $0.20/件（4 个月有效，售出或到期续期再收） |
| 交易费 | 6.5%（含运费） |
| 支付处理 | 4.4% + HK$2（HK）/ 3% + $0.25（US） |
| Offsite Ads | 12–15%（仅外部广告归因订单） |

合计最高约收入 25% → 定价要留足毛利。零前期投入，卖一单赚一单。
