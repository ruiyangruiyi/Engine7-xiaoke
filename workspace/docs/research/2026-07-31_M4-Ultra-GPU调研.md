## M4 Ultra 规格

| 规格 | 参数 |
|------|------|
| 架构 | Apple 自研 SoC，Metal 3 |
| GPU 核心 | 最多 80 核 |
| 统一内存 | 最大 512GB（CPU/GPU 共享） |
| 内存带宽 | ~800 GB/s |
| 神经网络引擎 | 32 核 |
| 制程 | TSMC 3nm |

## 关键特性：统一内存架构

- CPU 和 GPU 共享同一块内存，无 PCIe 瓶颈
- 模型直接躺在内存里，GPU 直接读
- 跑大模型天然优势：不需要"显存够不够装模型"的问题

## 跟 NVIDIA 对比

| | M4 Ultra 80核 (192GB) | RTX 4090 (24GB) | RTX 5090 (32GB) |
|---|---|---|---|
| 显存/内存 | 共享 192GB+ | 24GB GDDR6X | 32GB GDDR7 |
| 带宽 | ~800 GB/s | 1008 GB/s | 1792 GB/s |
| FP16 算力 | ~27 TFLOPS | ~83 TFLOPS | ~210 TFLOPS |
| 功耗 | ~80W (SoC) | 450W | 575W |
| 适合 | 大模型推理（内存大） | 训练+推理（算力强） | 训练+推理 |

**结论：算力不如 NVIDIA，但内存碾压。284B 模型 4090 装不下，M4 Ultra 随便装。**

## ds4 (DwarfStar 4) — antirez 的推理引擎

- GitHub: github.com/antirez/ds4
- 5.9k stars，MIT license
- 专为 DeepSeek V4 Flash (284B MoE) 设计
- 实测 M3 Max 128GB：26-27 tok/s
- 支持 1M token 上下文
- KV Cache 写 SSD（磁盘当扩展内存）
- OpenAI + Anthropic API 兼容
- 2-bit 非对称量化（只压 MoE expert）

### 硬件门槛

- 最低：96GB 内存 Mac（M3/M4 Max 顶配）
- 舒适：128GB+（M3/M4 Ultra）
- 16GB 笔记本：完全跑不了

### 跟我们的关系

- GLM 封号事件 → 本地推理不怕封
- token 零成本
- 1M 上下文 → 整个 workspace 塞进去
- 工具调用 + Agent 场景专门优化
