## 公开 API（export/）

### factory.h — 工厂入口
```cpp
// 创建 PushSender（推流端）
static PushSender* getNewPushSender(PushSenderCb* cb, void* userData);
// 创建 PullReceiver（拉流端）
static PullReceiver* getNewPullReceiver(PullReceiverCb* cb, void* audioMixer, void* userData);
// 已内置 dllexport/dllimport 宏（_WIN32 + CARPO_EXPORTS）
```

### PushSender.h — 推流接口
```cpp
setSSRC(audioSSRC, videoSSRC, uid)
setVideoBr(bps, min, max)        // 视频码率控制
setRtcServerAddr(ip, port)       // Carpo 服务端地址
startPush()
sendMediaData(type, buf, size, timestamp)  // ← 核心：传 H.264 NAL / Opus
stopPush()
// 回调：PushSenderCb::onPushEvent（BWE/超时/丢包/RTT）
```

### PullReceiver.h — 拉流接口
```cpp
setSSRC(type, audioSSRC, videoSSRC, uid)
setRtcServerAddr(ip, port, remoteIP)
start()
stop()
// 回调：PullReceiverCb::onMediaDataRecv(type, data, len, timestamp)  ← 核心：收 H.264 / Opus
// 回调：PullReceiverCb::onReceiverEvent（NetEQ延迟/连接超时/PCM音量）
```

### comDef.h — 类型定义
```cpp
enum CP_MEDIA_TYPE { CP_MEDIA_AUDIO, CP_MEDIA_VIDEO };
struct mediaDataT { buf, buf_len, timestamp, type };
```

1. **API 接口极干净** — PushSender/PullReceiver 只有 5-6 个方法，全是虚函数（纯 C++ 接口）
2. **Factory 模式** — 通过 `Factory::getNewPushSender()` 创建实例，隐藏实现
3. **已有 dllexport 宏** — `_WIN32 + CARPO_EXPORTS` 自动导出 DLL 符号
4. **Windows SDK 完整** — vcxproj + 预编译 lib + boost，编译链已跑通
5. **webrtc/ 占 825/778 文件** — 是最大的依赖负担，需要确定能否裁剪

## 补充分析（06:46）

### LiveBase.lib
- 只有 4 个源文件：dllmain.cpp + port.c + str_utils.c + utils.c
- port.c 是 oRTP（开源 RTP 库）的 Windows 移植
- 极小，可以直接编译或 stub

### webrtc/ 依赖精确分析
核心模块（src/ + RtpRtcp/ + Network/）只 include 了 **20 个** webrtc/ 头文件：

| webrtc 子目录 | 引用的头 | 用途 |
|---------------|----------|------|
| `modules/rtp_rtcp/` | rtp_header_parser, rtp_rtcp_defines, rtp_format, rtp_rtcp_config, remote_ntp_time_estimator | RTP 协议核心 |
| `modules/remote_bitrate_estimator/` | remote_bitrate_estimator (接口+实现) | 带宽估算 |
| `modules/video_coding/` | encoded_frame, internal_defines, receiver, timing | 视频帧管理 |
| `modules/audio_coding/` | audio_decoder, audio_decoder_opus, audio_decoder_aac, neteq | 音频解码 |
| `common_audio/` | signal_processing_library, webrtc_vad | 信号处理+VAD |
| `system_wrappers/` | clock, critical_section_wrapper | 系统抽象 |
| `modules/include/` | module_common_types | 公共类型 |

**结论：webrtc/ 825 个文件只需要保留约 6 个子目录（~200 文件），不需要全部编译。**
AEC/AGC/NS/audio_processing/media_file 等重模块可以去掉。
