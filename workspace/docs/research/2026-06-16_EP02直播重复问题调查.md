## 排除项（engine侧确认无问题）

### engine日志确认：
- 35次livestream_send，每次只提交1段文字
- 没有重复提交同一内容
- 1305限流跟重复时间点**没有一一对应关系**（最严重的04:19重复那个时间段没有1305）
- 不是preview/freeze导致的重复发送

### engine侧无法导致问题A和B：
- engine只是提交文字给AutoDL的 `/generate_pipeline_async` API
- 提交后AutoDL异步处理（TTS→FlashHead→RTMP）
- 重复和模糊都发生在AutoDL服务器侧
