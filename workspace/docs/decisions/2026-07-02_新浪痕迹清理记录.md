# 新浪痕迹清理记录

**日期**：2026-07-02
**背景**：Carpo SDK 原为新浪内部项目（2019-2020）。之前挂在工网（公司网络）测试时，被新浪安全扫描发现外发请求，翀哥被打电话通知。

## 清理范围

### 1. 外发 URL（高危）

| 文件 | 行号 | 原内容 | 处理 |
|------|------|--------|------|
| RTPTransport.cpp | 1394 | `http://api.ivideo.sina.com.cn/public/apilog?...lovepea_media_event` | `return;` 短路 |
| RTPTransport.cpp | 1526 | `http://api.ivideo.sina.com.cn/public/apilog?...lovepea_stream` | `return;` 短路 |
| CarpoEsLog.cpp | 70 | `http://api.ivideo.sina.com.cn/public/apilog?...lovepea_room_event` | `return;` 短路 |
| RTPTransport.cpp | 73 | `// http://i.api.ivideo.sina.com.cn/...` | 已注释，未处理 |

**处理方式**：在函数开头加 `return;` 跳过整个上报逻辑。不是删除函数体（保留代码结构，以后可能改成本地上报）。

### 2. 品牌字样（中危）

| 文件 | 原内容 | 新内容 |
|------|--------|--------|
| NetworkTaskPool.cpp:57 | `cJSON_CreateString("新浪科技")` | `cJSON_CreateString("Company")` |
| NetworkTaskPool.cpp:80 | `cJSON_CreateString("Sina")` | `cJSON_CreateString("Product")` |
| NetworkTaskPool.cpp:46 | `{"com":"新浪科技","products":["Meelive","Sina"]}` | 删除注释块内容 |

注意：这些代码在注释块内（`/* ... */`），不参与编译。但安全扫描器扫源码文本仍会命中。

### 3. Docker 代理凭据（高危）

| 文件 | 原内容 | 处理 |
|------|--------|------|
| Dockerfile | `ENV http_proxy http://squid:lepow123@lepow.net:3129/` | 替换为 `# proxy removed` |
| Dockerfile | `ENV https_proxy http://squid:lepow123@lepow.net:3129/` | 替换为 `# proxy removed` |

注：虽然这两行在 Dockerfile 中已被注释，但内含明文密码 `lepow123`，清理掉更安全。

### 4. Docker 镜像名

```bash
# 旧
registry.dpool.sina.com.cn/sinavideo/carpo:compile

# 新
carpo:compile
```

```bash
docker tag registry.dpool.sina.com.cn/sinavideo/carpo:compile carpo:compile
docker rmi registry.dpool.sina.com.cn/sinavideo/carpo:compile
```

## 未清理（保留）

### Copyright 头
大量文件有 `// Copyright © 2019 sina. All rights reserved.`

**保留原因**：
1. Copyright 是法律声明，不影响安全扫描（扫描器关注的是 URL/IP/凭据）
2. 改了反而显得心虚
3. 如果真要商用，走正规授权流程

### Android/iOS JNI 包名
`com/sina/carpo/CarpoPushSender` 等

**保留原因**：
1. 当前只编译 Windows 版，Android/iOS 代码不参与编译
2. 改了需要同步改 Java/Kotlin 端，工作量大
3. 不影响 Windows DLL
