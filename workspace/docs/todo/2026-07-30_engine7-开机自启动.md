# engine7 开机自启动服务 (#126)

> 创建：2026-07-30 10:00
> calendar: #126

## 背景

小白用户不会敲命令行，需要 engine7 开机自动启动。三个平台各用各的原生服务机制。

## 方案

新增 `engine7 service` 子命令：
- `engine7 service install` — 安装开机自启动
- `engine7 service uninstall` — 卸载
- `engine7 service status` — 查看状态

### Phase 1: engine7 service install/uninstall（Windows）
- [ ] 用 schtasks 创建计划任务
- [ ] 开机时运行 `engine7 start`
- [ ] uninstall 用 schtasks /delete

### Phase 2: engine7 service install/uninstall（Mac）
- [ ] 写 plist 到 ~/Library/LaunchAgents/com.engine7.plist
- [ ] launchctl load/unload
- [ ] uninstall 删 plist

### Phase 3: engine7 service install/uninstall（Linux）
- [ ] 写 .service 到 ~/.config/systemd/user/engine7.service
- [ ] systemctl --user enable/disable

### Phase 4: 验证 + rebuild + commit
- [ ] Windows 本机验证 schtasks
- [ ] 代码 commit

## 验证标准
- `engine7 service install` 后重启机器，engine7 自动启动
- `engine7 service uninstall` 后不再启动
- `engine7 service status` 显示当前状态
