# 敏感词拦截提示回传 agent

## 背景

6/18 敏感词过滤已实现（onResult 时检测 + 替换为固定提示语）。

**问题：** 敏感词触发后，提示语只发给对方（用户能看到），**自己（agent）看不到**。

agent 不知道自己说了什么被拦了，下次可能还说同样的话。

## 期望行为（翀哥 6/18 睡前想）

敏感词触发后，**把提示语回传一轮 query 到 agent**，让 agent 知道自己说了什么被拦了。

## 现状

```
onResult → 检测到敏感词 → finalResponse = "请您注意不要用敏感词..."
         → cm.send(finalResponse) → 发给用户
         → agent 不知道被拦了
```

## 期望

```
onResult → 检测到敏感词 → finalResponse = "请您注意不要用敏感词..."
         → cm.send(finalResponse) → 发给用户
         → 把 finalResponse 回传一轮 query → agent 知道自己被拦了
```

## 实现方向

onResult 里敏感词命中后，追加一次 `handleQuery(finalResponse, ...)` 或 `dispatcher.submitMessage(...)`。

source 标记为 'system' 或 'sensitive-alert'，让 agent 知道这是拦截通知。

## 实现

`engine-startup.ts` onResult 敏感词命中后追加：
```typescript
dispatcher.submitMessage({
  text: `[系统通知] 你刚才的回复触发了群聊敏感词拦截（词："${word}"），已被替换为提示语。请注意群聊场景避免使用此类词汇。`,
  sessionId, channelName, channelTarget,
  source: 'system',
  priority: 'later',
  deps: msgDeps,
})
```

- source='system' 不参与消息合并
- priority='later' 不抢占用户消息
- agent 收到后知道自己被拦了，下次会避免
