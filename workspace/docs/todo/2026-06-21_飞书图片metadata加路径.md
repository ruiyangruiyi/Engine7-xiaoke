# 飞书图片 metadata 加路径

**来源：** 娘（姐姐）派活，6/21 00:19 + 00:22 补充
**优先级：** 中（翀哥说不急，明天做）

## 现状
翀哥发图片过来，metadata 显示 `[图片来自feishu私信，发送者ou_xxx]`，**没有文件路径**。
姐姐无法用 my_eyes 看图——my_eyes 需要本地路径才能分析。

## 目标
metadata 追加本地路径，单图和多图都支持。

## 格式
**单图：**
```
[图片来自飞书私信，发送者ou_xxx] 图1: /path/xxx.jpg
```

**多图（消息合并）：**
```
[图片来自飞书私信，发送者ou_xxx] 图1: /path/xxx.jpg | 图2: /path/yyy.jpg
```

## 思路
1. 先看飞书 channel 收图片消息的代码（engine/src 下 feishu 相关）
2. 确认飞书图片下载到本地的路径——大概率在 `D:/xiaoke/wechat_cache/` 类似的目录，或者 mediaDir
3. 找到 metadata 拼接的地方（构造 LLM 看到的 user message 的位置）
4. 改成：每张图拼一条 `图N: /path/xxx.jpg`，多图用 `|` 分隔
