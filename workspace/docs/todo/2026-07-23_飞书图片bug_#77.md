1. 翀哥发飞书图片消息时，text 路径 + image 同时出现，应只保留 image

## 分析

### Bug 1: text + image 同时出现
- `extractContent` 对 `post` 类型消息同时提取 text 和 imageKeys
- inbound message 同时有 content + attachments
- 下游处理可能分别走了 text 和 image 两条路径

### Bug 2: 5张图只进4张
- 翀哥一次发 5 张图（飞书多图消息）
- 飞书可能拆成多条消息或 post 内嵌多图
- `_downloadImage` 失败只打日志不 throw，可能第 5 张下载失败被跳过
