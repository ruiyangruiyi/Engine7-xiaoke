# preview/toolUse/toolResult 精细化控制

## 背景

6/19 翀哥提：preview 卡片对客户不友好——中间过程（tool use、tool result）暴露给客户体验差。

需要按 group 维度精细化控制 preview / toolUse / toolResult 的显示。

## 现状

- preview 卡片：全局有 previewEnabled 配置
- 敏感词过滤：有 groupSensitiveWords（已配）
- 没有 toolUse / toolResult 显隐配置
- 没有按 group 维度细分的 preview 控制

## 期望行为（翀哥 6/19 定）

**1. preview 显示控制（按 group）**
- 默认不显示
- 用于敏感词过滤这套（既然敏感词在群里被拦截，不显示中间过程更合理）

**2. toolUse / toolResult 显示控制（按 group）**
- 默认不显示
- 中间过程不需要暴露给客户

**3. 配置位置**
- 跟敏感词放一起：`channel.feishu.group`（每个 group 节点下统一配）
- 包括：
  - `preview`: bool
  - `toolUse`: bool
  - `toolResult`: bool
- 默认值都是 false

3. 默认 false（不显示），跟现状兼容
