**安装流程没验证过，给客户装出问题就麻烦。**

## 现状

- Engine 7 是 6/15-6/17 自研的，部署在 翀哥本地
- 没在干净机器上装过

**自动化的安装验证脚本，能跑完整链路并报告通过/失败项。**

## 验证清单

1. **全新机器从零安装**
   - Node 18+ / npm
   - git clone → npm install → tsc/esbuild build
2. **配置文件初始化**
   - default config 模板
   - 修改（API key、模型、通道）
   - 启动并验证启动
3. **三通道启动验证**
   - discord 登录 + 消息收发
   - feishu 登录 + 消息收发
   - wechat 登录 + 消息收发
4. **依赖服务**
   - GPT-SoVITS 语音
   - playwright MCP 浏览器
   - sessions 持久化路径
5. **license 验证（如果有）**

## 实现方向

- 写 `install-verify.cmd` / `install-verify.sh`
- 跑完整链路并报告
- 失败项清晰定位
