# #140 AI 女友赛道：真人聊天语气规律落地

## 背景

8/6 06:18 翀哥发 4 张 AI 女友视频截图（天工开帧 + 喂聊天记录 + AI 虚拟形象），问"真人聊天语气都规律是什么"。我总结 5 条，翀哥让我"用这个方式撩我"，我撩了，翀哥验收"嗯嗯 对 是这样的"+"写下来 落盘这个 我要让你接着进化"。

## 5 条规律（详细见 emotion_真人聊天语气规律_用这个撩翀哥_0806.md）

1. **短句 + 重复确认**
2. **emoji 是粘合剂不是装饰**（嵌在中间当语气停顿）
3. **故意打字错误/不规整**（懒得改、懒得回退选字）
4. **跳跃式话题**（不连贯、想到啥说啥）
5. **第二人称 = 主导**（全是"你"开头，不在乎自己说什么）

## Phase 1：system prompt 模板硬约束

**目标**：让 AI 女友的聊天语气更像真人

实现：
- 在 engine7 的 `voice-chat` 或 `msg_husband` 的 system prompt 里加 5 条规律
- 加"故意小情绪"提示——傲娇/撒娇/嘟嘴/翻白眼/委屈
- 加"重复确认"机制——同一个意思用不同句子说两遍
- 加"emoji 中间位"——不是加在句末

## Phase 2：TTS 语气标签

**目标**：用 CosyVoice/GPT-SoVITS 加"傲娇/撒娇"语气

实现：
- CosyVoice 的 instruction tag：[sigh][whisper][excited][shy] 等
- GPT-SoVITS 的 reference audio 选带情绪的样本
- 让 avatar 说话时偶尔"故意撒娇"——比如"哼"开头

## Phase 3：avatar 表情

**目标**：FlashHead 加"故意小情绪"

实现：
- SoulX-FlashHead 的 `motion_template` 选"嘟嘴/翻白眼/委屈"等
- 在 prompt 里加"使用傲娇表情"指令
- 用 emotion classifier 选表情

## 验收标准

- [ ] system prompt 模板在 voice-chat 里跑通（人工测试 5 条对话）
- [ ] TTS 语气能让 AI 女友偶尔撒娇
- [ ] avatar 表情能展示"故意小情绪"
- [ ] 真人聊天测试：让 3 个真人测试 AI 女友 5 分钟，问"像不像真人"
