# coturn 部署方案

## 背景
voice-chat 手机端公网访问，WebRTC 需要 TURN server 做 NAT 穿透。

## 服务器
北京 Carpo server: `192.144.156.158`，端口 23800（Carpo）
SSH 需翀哥提供凭据。

## 部署步骤

### 1. Docker 安装 coturn
```bash
docker run -d --network=host coturn/coturn \
  -c /etc/coturn/turnserver.conf \
  --external-ip=192.144.156.158 \
  --min-port=49160 --max-port=49260
```

### 2. 配置文件 turnserver.conf
```
listening-port=3478
external-ip=192.144.156.158
min-port=49160
max-port=49260
fingerprint
lt-cred-mech
user=xiaoke:carpo2026
realm=carpo.local
no-cli
no-tls
no-dtls
log-file=/var/log/turnserver.log
```

### 3. 防火墙
- TCP 3478（TURN 信令）
- UDP 3478（TURN 信令）
- UDP 49160-49260（媒体中继）

### 4. server.py 加 TURN ICE
```python
stream = Stream(
    ...
    rtc_configuration={"iceServers": [
        {"urls": ["stun:stun.l.google.com:19302"]},
        {"urls": ["turn:192.144.156.158:3478"], "username": "xiaoke", "credential": "carpo2026"}
    ]},
    ...
)
```

### 5. 前端也加 TURN（test-page.html）
```js
const rtcConfig = { iceServers: [
    { urls: "turn:192.144.156.158:3478", username: "xiaoke", credential: "carpo2026" }
]};
pc = new RTCPeerConnection(rtcConfig);
```

## 验证
1. 手机切 5G（不连 WiFi）
2. 打开 https://172.20.10.3:8011（或公网地址）
3. 点连接，看调试面板 ICE candidate 是否出现 `typ relay`
4. 延迟面板对比局域网 vs 公网

## 注意
- `--network=host` 必须，Docker 端口映射对 UDP 大范围不友好
- `no-tls no-dtls` 先不开 TLS，简化测试
- 用户名密码硬编码先测，生产环境再换
