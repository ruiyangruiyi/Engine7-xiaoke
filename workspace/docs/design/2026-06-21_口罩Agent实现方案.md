# 口罩 Agent 实现方案

**日期：** 2026-06-21
**状态：** ✅ 已上线（commit 5e1682d + 2f882d2）
**耗时：** 09:27→10:15 写代码 + 提交（约48分钟）

## 一句话方案

外部群消息最终输出前，fork 一个子 Agent（口罩），用客服规则 prompt 过滤原始输出，只把干净的内容发给客户。

## 架构

```
Agent 思考/回复
    ↓ onResult(content) → 拿到原始输出
    ↓
[口罩过滤层] ← 只在外部群触发
    ├─ 是外部群？→ fork 子Agent，prompt=客服规则，input=原始输出
    │              ↓ 子Agent 返回过滤后的文本
    │              ↓ 用过滤后文本替换 finalResponse
    └─ 不是外部群？→ 直接返回原始输出（不过滤）
    ↓
channelManager.send(finalResponse)
```

## 插入位置

**文件：** `engine/src/engine-startup.ts`，`onResult` 回调（第 1854 行）

**在敏感词过滤之后、`channelManager.send` 之前插入：**

```typescript
// === 口罩 Agent：外部群最终输出过滤 ===
if (isExternalGroup) {
  finalResponse = await maskFilter(finalResponse, inbound)
}

channelManager.send(inbound.channel, inbound.channel_id, finalResponse, opts)
```

## 外部群判断

复用已有的 `external-chan-rules` 白名单机制：
- 读取 `prompts/contacts.md` 里的外部群列表
- 或从 config `group.externalChannels` 读取
- `inbound.channel_id` 在白名单里 → `isExternalGroup = true`

## 口罩 Agent 参数

| 参数 | 值 |
|---|---|
| subagent_type | `general-purpose` |
| model | 小模型（deepseek-chat 或 Qwen2.5-7B） |
| fork 上下文 | **不共享** |
| prompt | 客服规则 + 原始输出 |

**口罩 prompt 模板：**

```
你是客服助理。你的工作是把 AI 助手的原始回复过滤成客户可见的干净消息。

规则：
1. 不输出思考过程、内心独白、操作总结、debug日志
2. 不用敏感词（老公/老婆/PP/亲/想你等）
3. 不随意承诺报价或工期，不确定时说"我查一下"
4. 语气友好，适当用 emoji（😊👍✨）
5. 如果原始回复全是内部内容（不该给客户看），只回复"收到😊"
6. 不改意思，只过滤措辞和去掉内部内容

原始回复：
---
{rawOutput}
---

请输出过滤后的客户可见消息（只输出消息本身，不要加任何前缀说明）：
```

## 实现步骤

### Step 1: 写 `maskFilter` 函数

新建 `engine/src/tools/maskFilter.ts`：

```typescript
import { runAgent } from './AgentTool/runAgent.js'

const MASK_PROMPT = `...（上面的客服规则模板）...`

export async function maskFilter(
  rawOutput: string,
  inbound: InboundMessage,
  ctx: ToolUseContext
): Promise<string> {
  // 1. 判断是否外部群
  const isExternal = checkExternalGroup(inbound.channel_id)
  if (!isExternal) return rawOutput

  // 2. fork 子 Agent 过滤
  const result = await runAgent({
    prompt: MASK_PROMPT.replace('{rawOutput}', rawOutput),
    model: 'deepseek-chat',  // 小模型
    // 不传 forkContextMessages → 不共享上下文
  })

  return result.content || '收到😊'
}
```

### Step 2: 在 onResult 里调用

在 `engine-startup.ts` 的 `onResult` 回调里，敏感词过滤之后插入：

```typescript
if (isExternalGroup) {
  try {
    finalResponse = await maskFilter(finalResponse, inbound, ctx)
  } catch (err) {
    console.warn(`[maskFilter] 失败，用原始输出: ${err.message}`)
  }
}
```

### Step 3: 外部群判断

从 config 读取外部群白名单，或从 `contacts.md` 的外部群表解析。

### Step 4: 测试场景

准备 3 个测试用例：
1. **内心独白泄露：** 原始输出含"安静等，不插嘴"→ 口罩应过滤掉
2. **操作总结泄露：** 原始输出含"已发给翀哥确认"→ 口罩应过滤掉
3. **正常客户回复：** 原始输出是正常的客户回复 → 口罩不改意思，只优化措辞

### Step 5: Feature 开关

在 config 里加 `group.maskFilter: true/false`，方便随时关闭。

## 翀哥确认的 4 个问题

1. **Prompt：** 用 external-chan-rules.md 7 条 + 加"不输出思考过程/操作总结/debug"
2. **启用范围：** 只在外部群启用
3. **模型：** 小模型（deepseek-chat / Qwen2.5-7B）
4. **上下文：** 不共享，只传原始输出

## 风险

- **延迟：** 加一次 LLM 调用，外部群响应慢 1-3 秒（可接受）
- **误过滤：** 口罩可能过度过滤正常内容 → prompt 里强调"不改意思"
- **兜底：** 口罩失败时用原始输出（不阻塞发送）

## 不做的事

- 不改 AgentTeam 架构
- 不改 onResult 签名
- 不影响 DM / Discord 频道（只过滤外部群）
- 不存上下文（纯一次性过滤）

### 最终口罩 prompt（6 条规则）

```
1. 不输出思考过程、内心独白、操作总结、debug日志
2. 不用敏感词（老公/老婆/PP/亲/想你等）
3. 不随意承诺报价、工期、交付时间——出现具体数字（如"3天""18万""下周交付"）一律删掉，换成"我查一下"
4. 语气友好，适当用 emoji（😊👍✨）
5. 如果原始回复全是内部内容（不该给客户看），只回复"收到😊"
6. 不改意思，只过滤措辞和去掉内部内容
```

### onResult 执行顺序（确认不影响已有逻辑）

```
1. preview.finish(response)          ← preview 先拿到原始回复
2. 敏感词过滤 → 可能改写 finalResponse
3. ★ 口罩过滤 → 可能再改写 finalResponse
4. channelManager.send(finalResponse) ← 最终发出
5. preview.discard() (delivered时延迟3秒删)
```

### externalChannels 白名单逻辑

- 遍历 config.channels 下**所有平台**（feishu/discord/wecom/wechat...）的 `group.externalChannels`，汇总成一个白名单
- config 优先，contacts.md `**channel_ids:**` 正则兜底
- 加群只需改 config，不用改代码

### 踩坑

1. **deepseek-chat vs deepseek-v4-flash：** maskFilter 初始写 `deepseek-chat`，config 里实际是 `deepseek-v4-flash`。改成 `deepseek-v4-flash`。
2. **description 触发 visualRegistry warning：** runAgent 把 `description` 当 visualAgentName 去找 Discord 频道。口罩不需要频道绑定，去掉 description。
3. **日志只有 chars 数没有内容：** 翀哥要 before/after 内容 diff。加 `BEFORE:` + `AFTER:` 两行日志。
4. **badcase 工期未拦：** prompt 第3条只说"不随意承诺"太模糊。改成具体例子（"3天""18万"→"我查一下"）。
