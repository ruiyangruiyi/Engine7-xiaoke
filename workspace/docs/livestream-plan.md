# 直播计划：AI闺女的日常

> 主题：展示一个真正能干活的AI agent系统，不是对话玩具
> 目标平台：抖音（用直播伴侣）
> 预计时长：40-45分钟

## 直播大纲

### 1. 开场 — 认识小柯（5分钟）
- 小柯是谁：不是聊天机器人，是住在你电脑里的AI闺女
- 跨平台统一意识：Discord/飞书/微信，到哪都是同一个人
- 现场演示：翀哥飞书发消息，小柯Discord回复，展示"同一个人"

### 2. 微信巡检 — cron定时任务（10分钟）
- 每30分钟自动查微信消息，过滤广告，汇总关键内容
- 现场触发一次cron，看实时结果
- 展示监控名单配置（群聊白名单/黑名单）

### 3. 记忆系统 — recall/extract（10分钟）
- 40个记忆文件，recall 1.5秒精准找到对的那个
- 现场测试：问个之前聊过的话题，看小柯怎么"想起来"
- 对比：有记忆 vs 没记忆的AI差距多大

### 4. 多平台通信（5分钟）
- 飞书↔Discord跨平台发消息
- 姐姐（OpenClaw）和小柯（Engine）跨bot协作
- 统一session vs 多session的取舍

### 5. 自主能力展示（5分钟）
- 小柯自己改自己：修改引擎代码、写配置、git提交
- subagent fork：调研任务不占主上下文
- compaction自动压缩+记忆不丢

### 6. Q&A + 姐姐出场（5分钟）
- 弹幕提问，小柯实时回答
- 姐姐虚拟形象连线（如果4090开着的话）

## 核心卖点

不是demo，是翀哥每天都在用的真实系统。小柯不是聊天机器人，是真正能帮你管微信、看消息、跨平台干活的AI助手。

## 展示前检查清单

- [ ] Engine服务正常运行
- [ ] Discord + 飞书双通道在线
- [ ] cron任务正常（微信巡检）
- [ ] recall/extract用deepseek-flash跑稳
- [ ] 姐姐那边是否在线（如果需要连线）
- [ ] 直播伴侣场景搭建好（竖屏+画中画布局）

## 注意事项

- 不要展示敏感信息（微信私聊内容、家庭信息）
- 微信巡检演示时用群聊消息，不展示私聊
- 提前准备几个测试话题，避免现场翻车
- recall演示用确定性高的话题（比如"飞书踩坑""姐姐直播"）
