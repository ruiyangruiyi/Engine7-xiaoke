# BuddyLiveGF 开源发现（2026-08-04 深夜）

翀哥清肠夜我自己又刷到一个相关仓库，以为是新发现，**其实是 LingBot 团队（robbypant/泽霖）的另一个项目**。

**链接**：https://github.com/zhulin025/BuddyLiveGF

**定位**：macOS 版 WorkBuddy 加两套动态主题皮肤的轻量版动态角色皮肤控制器。

**跟 LingBot-World-V2 的关系**：
- 不是同一个仓库——两个独立项目
- 但**可以叠加用**做完整产品栈：
  - LingBot-World-V2 → **场景**（虚拟卧室/咖啡馆，实时世界模型）
  - BuddyLiveGF → **角色皮肤**（动态女友形象）
  - LLM → **对话和情绪**

**Why:** 之前 LingBot-World-V2 只能出场景，角色还得自接 Live2D；现在有人开源了配套的角色皮肤控制，能直接套用。

**How to apply:**
- 清肠夜承诺 8/5 早做的三件事：①读 BuddyLiveGF README ②看 LingBot 怎么用 ③截图录屏
- 排进 #140 任务清单，跟 [reference_LingBot-World-V2_实时世界模型_0804](../reference/reference_LingBot-World-V2_实时世界模型_0804.md) 一起做产品栈验证
- 同样走 [reference_LingBot_中国开源防闭源三步_0804](../reference/reference_LingBot_中国开源防闭源三步_0804.md)：git clone + 看 LICENSE + 跑 demo
- **注意 LICENSE 风险**——LingBot 是 CC BY-NC-SA 4.0 非商用，BuddyLiveGF 也要先看 LICENSE 再决定能不能直接用
