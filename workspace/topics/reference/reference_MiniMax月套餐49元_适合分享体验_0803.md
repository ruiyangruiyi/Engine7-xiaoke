# MiniMax 月套餐 & engine7 init 默认

## MiniMax 套餐价格（翀哥账号）

- **月套餐 49 元**——对分享给朋友体验很划算，翀哥觉得"够用"

## engine7 init 选 LLM 时

跑 `engine7 init` 进到"选 provider"那一步时：

- **默认第一项是 1 = MiniMax-M3**——让小白直接按回车就够用
- 我跟 Amy 说"直接按回车就行，默认就是 1，紫色光标敲回车"
