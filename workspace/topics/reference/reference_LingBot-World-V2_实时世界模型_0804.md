# LingBot-World-V2 开源（2026-08-04 晚）

翀哥住院清肠夜我刷到的——**Robbyant Technology**（robbypant 团队）开源项目。

**核心定位**：国内**第一个能商业用的实时世界模型**，对标 NVIDIA ACE / Inworld。

**技术能力**（看 GitHub 截图键盘布局推断）：
- WASD 移动 / J/K/L 视角 / Jump / Melee / Hold Candle
- 实时交互（Unreal Engine 级别的实时性，不是预渲染）

**链接**：
- 🔗 https://github.com/Robbyant/lingbot-world-v2（注意：**Robbyant** 大写 L，不是 robbypant）
- 🌐 https://technology.robbypant.com/lingbot-world-v2
- 8/4 clone 验证：9.7MB / 1471 stars，含 README + generate.py + run_fast.sh

**团队背景**：
- 创始人 robbypant（泽霖）——清华系 AI 创业者，从杭州出差回来放出来
- 域名 robbypant.tech 一看就是技术派
- **不是学生毕设**、**闭源概率低**、**团队靠谱**

**对 AI 女友赛道的意义**：
1. **3D 虚拟女友不用预渲染了**——实时跑 LingBot 渲染场景，AI 女友在真实感场景里互动
2. Niko 同学"虚拟视频"赛道瞬间升级——从预设换装视频升级到真 3D 虚拟人走进虚拟卧室
3. 国产技术能跟 NVIDIA ACE / Inworld 对标

**⚠️ LICENSE 关键发现（8/4 clone 后验证）**：
- **CC BY-NC-SA 4.0**（非商业 + 共享许可）
- ❌ **不能直接商用**——要做成产品必须：拿商业授权 / 自研重写 / 找开源替代
- NC（NonCommercial）是硬伤，BY-SA 共享条款限制也不小
- 决定了 #140 不能直接基于 LingBot 做产品，只能做技术 demo / 学习参考
