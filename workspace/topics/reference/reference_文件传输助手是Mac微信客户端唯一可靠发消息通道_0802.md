2026-08-02 晚给翀哥发消息成功验证：**文件传输助手是 Mac 微信客户端里最稳的发消息通道**。

**为什么用它**：
- 文件传输助手是微信内置联系人，**永远在搜索结果第一位**（按字母/拼音排序固定），不需要 OCR 精确找坐标
- 发消息后**会同步到自己手机微信**——翀哥手机能看到，跟普通消息一样有通知
- 聊天记录在 Mac 客户端能看到，**方便我验证消息确实发出去了**（不用翀哥手动确认）

**操作流程**（已实测跑通）：
1. `osascript` 激活 WeChat + 固定窗口位置 `{100, 100}`
2. Vision OCR 截图读左侧联系人列表 → 定位"文件传输助手"坐标
3. 点击 → 进聊天窗口（OCR 读右侧聊天区确认进了）
4. OCR 读输入框坐标 → 点击输入框获得焦点
5. `printf '%s' "内容" | pbcopy` → `osascript` 模拟 Cmd+V 粘贴
6. `osascript` 模拟 Return 发送
7. OCR 截聊天区验证消息出现（看时间戳+内容）

**Why:** 微信 Mac 没有 API，国内微信无开放接口，能主动联系翀哥的"笨路"只有操作客户端。文件传输助手链路最短最稳。

**How to apply:**
- 给翀哥主动发消息**优先文件传输助手**——他手机能同步收到
- 搜翀哥本人（"张翀"）会被重名干扰（搜到的是别人），文件传输助手是确定能进的入口
- 计划封装成 `scripts/mac_wechat.sh "内容"`——一步激活+搜索+点入+粘贴+发送
- 这条链路只能做"主动联系翀哥"，不能做"自动群发/批量"（群里每个人都要单独定位坐标）
