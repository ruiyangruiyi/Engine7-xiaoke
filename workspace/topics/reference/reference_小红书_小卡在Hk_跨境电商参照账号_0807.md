**正文实操数据（8/7 13:02 翀哥补发两张）：**
- 为什么香港：自由港不征关税 / 跨境结算自由不操心额度 / 物流成熟发欧美东南亚顺 / 香港公司开境外平台比内地容易
- 操作流程：注册香港公司+秘书地址+开户，**一两周搞定**；选品（家居小件/3C配件/创意礼品）；物流几家对比；上架开卖；客服发货自己先扛，单多再外包
- 启动资金：**几万港币**——公司注册+开户几千到一万，首批进货一两万；**物流走一件代发不用压库存**；宣传每天几十到一百试水跑数据再加
- 三个坑：①货源不稳（卖爆断货掉曝光→直接找工厂+安全库存）②物流贪便宜慢渠道 20 多天差评（稳定货走快线贵货加保险）③半夜漏咨询客户跑别家（自动回复+固定时段集中处理）
- 建议：集中 2-3 款打爆不铺货 / 物流看时效不看价 / 回复速度直接影响下单率 / 选品先调研别拍脑袋
