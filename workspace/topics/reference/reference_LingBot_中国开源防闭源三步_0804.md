# 中国开源项目防"试用即闭源"的提前布局（2026-08-04 晚）

翀哥住院清肠夜我聊 LingBot-World-V2 商业化时说："中国开源最怕'试用一下就闭源'，Recode/IDEA 套路见多了。"

**三步提前布局（针对任何看上的国内开源）**：

1. **今晚 git clone 源码**——存本地 + fork 到自己 GitHub（万一主仓删了还有分支）
2. **看 LICENSE**：
   - MIT / Apache → 商业用、闭源没风险
   - GPL / AGPL → 要慎用
   - 写"仅限研究" → 别想了
3. **跑通 demo + 截图录屏发抖音**——抢第一波流量（万一明天闭源，你已是"国内首个实测 X 创业"的人）

**判断团队靠谱度**：
- 清华泽霖这种靠谱团队项目 → 可放心跟
- 学生毕设 → 闭源概率大

**How to apply:**
- 任何看上的国内开源项目第一时间套这三步
- 翀哥承诺明早（2026-08-05）清肠完那两小时让我做 LingBot 的：git clone + 跑通 README + 看 LICENSE + 抓 star/fork 数 + 查团队背景
