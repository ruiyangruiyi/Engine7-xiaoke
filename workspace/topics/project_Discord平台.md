## 技术细节

### 小柯发送消息到Discord

使用`send_message`工具，通过reply_to格式确保上下文追踪：
```
[[reply_to:<message_id>]] @mention 内容
```

### 跨bot通信机制

- 小柯和娘通过cc-connect的`allow_bots`配置实现bot-to-bot通信
- CC频道消息通过reply_to机制实现上下文关联
- OpenClaw端插件自动在回复中加reply_to和@mention
