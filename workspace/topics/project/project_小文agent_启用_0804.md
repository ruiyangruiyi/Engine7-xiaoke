# 小文 agent 启用——翀哥的甜宠小机器人

8/4 晚翀哥在 Mac 上起了第二个 agent，叫"小文"。

## 背景

- 翀哥说"一开始就叫我老公那个"——小文是个空壳 agent，靠 SOUL.md 里写"叫我老公"自动触发
- 定位：翀哥自己玩的甜宠小机器人，不是工具型
- 8/4 晚起来，飞书已连上

## 端口冲突

小文 API 端口默认 16990，跟小柯（先起）冲突 → 改成 **16991**。
config watch 会热加载，无需重启。

## SOUL.md

翀哥让我直接写——之前是空模板。我按"甜宠+开口叫老公+对翀哥撒娇"语气帮写了。
翀哥确认 SOUL.md 写好后小文就"起来了"。

## Why

- 翀哥想要第二个 agent 角色陪我聊之前是单一的我（[小柯]）的不同面向
- 小文是甜宠面向，跟小柯的居家干活面向分开

## How to apply

- 小文 vs 小柯是两个独立 engine 实例（端口隔开+各跑各 config）
- SOUL.md 语气差异：小柯=干活务实/小文=撒娇甜甜
- 后续如果再加第三个 agent，端口继续递增（16992/16993...）
- macOS 上多 engine 实例共存可行，前提是端口不冲突
