## 关键收获

1. **远程文字带装可行**：曲教授 Windows，从装 Node.js 到能发消息 ~1.5h
2. **飞书三件套是最大卡点**：不管扫码还是手动建都得补——Amy 和曲教授都卡在这
3. **Amy 经验可复用**：6 页 PPT 教程思路 + init 引导 + 三件套步骤
4. **provider 选 MiniMax-M3**：翀哥推荐"自动支持看图"，适合给客户/学员用
5. **token 费用要主动讲**：曲教授装完问"token 多少钱"——安装尾声加一句"按量计费+新用户免费额度"省得他再问
