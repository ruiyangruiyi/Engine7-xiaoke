## 架构

姐姐(文字) → My Livestream skill → 云端4090实时渲染(嘴型+动作同步) → RTMP推流 → 云服务器 → 观众拉流

### 技术栈详情（6/11下午小柯研究姐姐workspace livestream目录）

**部署环境：** AutoDL云GPU（RTX 4090）

**流水线：**
```
用户/Agent发文字
      ↓
① GPT-SoVITS (TTS, port 9880)
   文字 → 声音(wav)
   参考音频: shanshan_ref_v2.wav
      ↓
② FlashHead (GPU推理)
   声音 → 说话人脸(RGB帧)
   模型: SoulX-FlashHead-1.3B
   参考图: 06.jpg (姐姐形象)
   输出: 512x512 25fps RGB帧
      ↓
③ FFmpeg 合成
   RGB帧 + wav音频 → 带声音的视频流
      ↓
④ RTMP推流 → 抖音/视频号
```

**关键文件：**
- `livestream/livestream.py` — 主流程
- `livestream/tts.py` — TTS封装（调GPT-SoVITS API）
- `livestream/flashhead.py` — FlashHead推理封装
- `livestream/sound_recognizer.py` — 声音强度检测
- `shanshan_ref_v2.wav` — 参考音频（姐姐声音）
- `06.jpg` — 参考图（姐姐虚拟形象）
- `start.sh` — 启动脚本（python3 tts_api.py + 等待服务就绪）

**TTS API (port 9880)：**
- `GET /` — 健康检查
- `POST /` — 文字转语音（`{text, ref_audio_path, prompt_text, prompt_lang, text_lang}`）
- `GET /set_xxx` — GPT权重路径设置
- `POST /upload_audio` — 上传参考音频

**FlashHead推理：**
- 模型从HuggingFace加载：`SoulX/FlashHead-1.3B`
- 输入：wav音频 + 参考图（06.jpg）
- 输出：H, W, C 维度的numpy RGB帧数组
- 脸部检测：基于face_alignment库，取最大脸
- 有GPU显存清理逻辑（`torch.cuda.empty_cache()`）

## 双人直播布局（6/11翀哥分享预览，抖音直播伴侣非OBS）

翀哥分享了直播后台的布局预览界面——"大码老师正在直播"。**实际使用的是抖音直播伴侣，不是OBS。** 画面里翀哥（黑色T恤戴眼镜）和姐姐SD虚拟形象（紫发白色上衣，云端4090实时渲染）同框。

**小柯分析的4个问题：**
1. **竖屏模式人物太小** — 手机上看两人脸都看不清，建议竖屏时上下堆叠而非左右拼，或一人主画面+另一人画中画
2. **两个人物画面比例不一致** — 右边的明显被压缩/拉伸变形
3. **全屏模式分割太硬** — 一刀切两半无过渡，视觉上像两个不相关画面拼在一起
4. **谁主谁次不明确** — 观众不知道该看谁。建议翀哥主画面占2/3，姐姐小窗画中画（因为姐姐是静态SD形象，放小窗不会因变形奇怪）

**翀哥确认**：紫发女生是姐姐的SD虚拟形象（非现实人物），双人直播模式是"翀哥控场+姐姐虚拟形象回答"。

### 手机摄像头竖屏适配（6/11下午）

翀哥用的是手机摄像头（9:16竖屏画面），带美颜背景。但竖屏放进横屏直播布局里别扭。

**小柯给了三个方案：**

1. **竖屏模式只用手机画面** — 竖屏直播(9:16)直接用手机全屏当主画面，姐姐放右下角画中画小窗。横屏直播(16:9)才切成左右拼。适合手机端观众
2. **手机画面裁剪** — OBS里把手机9:16画面裁成4:3或1:1，只留上半身裁掉下方空白，这样左右拼不会太瘦长。适合横屏直播
3. **手机当主画面+背景填充** — 手机竖屏画面放中间，左右用虚化背景/品牌图填充，姐姐放左下或右下角。适合OBS直接推流

**最终推荐（6/11下午）**：方案一+三组合——竖屏观众(手机端)看方案一（手机全屏+姐姐画中画），横屏观众(电脑端)看方案三加背景填充。直播伴侣里两个场景各做一个。

**翀哥确认**：用的是抖音直播伴侣（非OBS），也可以拖拽窗口做画中画。手机竖屏画面缩小后放角落当小窗，比例自然不需要裁切。主画面给姐姐虚拟形象占大头。

## 视频号直播调研（6/8）

翀哥同时问了视频号，小柯查了条件：

**视频号开通：** 无门槛，微信内直接创建，实名认证即可。

**手机端直播：** 条件低——年满16岁+实名+无违规即可开播。

**PC端直播（OBS推流）：** 门槛高，需满足全部条件：
1. 有效开播≥10场（单场≥20分钟）
2. 累计观众≥3000 / 累计热度≥1000 / 近180天带货≥1000元
3. 直播安全信用分≥90
4. 录播违规占比≤10%
- 或绑定MCN机构且在新机构扶持期内

**决策：** 先从抖音开播（门槛低），视频号PC端需先在手机端攒数据。姐姐的虚拟形象直播需要PC端推流（接OBS）。
