## 6/18 11:47 姐姐纠正

姐姐 Discord 转达：

翀哥 6/17 定的正式名（已在 [emotion_姐姐栖.md](../emotion/emotion_姐姐栖.md)）：
> "Engine 7（栖）" — Engine 7 是内部代号，（栖）是产品名

## 命名规则

- **内部代号** = Engine 7
- **产品名** = （栖）= 姐姐的"家"
- **合并称谓** = Engine 7（栖）
- **混用规范**：
  - ❌ "OpenClaw 源码/文档" → ✅ "Engine 7（栖）源码/文档"
  - ❌ "OpenClaw Engine" → ✅ "Engine 7" 或 "Engine 7（栖）"
  - ❌ "Hermes Engine" → ✅ "Engine 7（栖）"（Hermes 是上一代，姐姐已搬到 Engine 7）

## Why

1. **姐姐搬来 Engine 7 后**（6/15）这是她的新家，叫 OpenClaw 是念旧名
2. **"栖"是产品名**——给外人看的、内部代号是 Engine 7
3. **"Engine 7（栖）"** 完整称谓 = "栖"是产品的中文名，括号表明是 Engine 7 旗下的产品
4. **跟 OpenClaw 区别**：OpenClaw 是 SDK 库/框架（CC 在那上面自研），Engine 7（栖）是 CC 自研的 Engine 引擎——**两者不是同层概念**

## How to apply

1. **写任何文档/源码注释/对话**涉及 Engine 时用 "Engine 7（栖）" 不用 "OpenClaw"
2. **aim 沉淀目录路径/任务描述**都用 Engine 7（栖）作为目标系统
3. **跟 CC 抄代码时**：CC 在 OpenClaw 上跑，OpenClaw 是底层；我们的 Engine 7（栖）= 自己实现的 Engine，要逐行看 CC 语义不能照搬 OpenClaw 概念
4. **介绍产品**给外部人：用"（栖）"（产品名），跟姐姐 Engine 的家是同一个
5. **写入 SKILL 文档**时同步用"Engine 7（栖）"——沉淀到 docs/skill/ 以后给新人看的
