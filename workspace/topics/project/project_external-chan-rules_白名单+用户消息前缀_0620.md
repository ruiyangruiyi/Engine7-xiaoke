## 完整方案

### 4道关卡（handle-query.ts formatUserMsg或getExternalChanRulesBlock）
1. `channel !== 'feishu'` → 不注入
2. `channelType === 'dm'` → 不注入
3. `!channel_id` → 不注入
4. `channel_id` 不在白名单 → 不注入

### 白名单从 contacts.md 读取
- 原硬编码在白名单数组 → 从 contacts.md 通过 `**channel_ids:**` 正则提取
- 一行搞定，不管 `##` 哪一层级、不管区段在哪
- 要加新外部群只需编辑 contacts.md，不用动代码

```

block[1] [系统规则]
```

### DM/Discord/其他（白名单外）
