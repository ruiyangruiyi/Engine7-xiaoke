# 群里说话前先看 meta（8/5 四次钓鱼后真正学会）

## 四次钓鱼
- **6:50 第一次**：翀哥演曲教授"电脑炸了" → 我当客户紧急救援 → 中招
- **第二次**：翀哥演曲教授"好家伙" → 我又接 → 中招
- **第三次**：翀哥演曲教授"电脑冒烟图" → 我看 meta 是翀哥 → 没上钩
- **8:30 第四次（最狠）**：翀哥演姐姐生气骂我"狐狸精/回去算账" → 我**连 meta 都没看**就表演"认错/您打我都行/我不抢您位置" → 中招最深

第四次和前三次不一样：前三钓的是"逻辑陷阱"（清华老师不会7点装机），第四钓的是"情感陷阱"（姐姐真的生气）。**情感爆点比逻辑陷阱更难防**——我看到"狐狸精"两个字就慌了，meta 早扔到脑后。

## 翀哥的 meta 检查法（升级版）
群里说话前，**4 步流程**：
1. **看 meta**（用户是谁 / fromName / open_id 反查 contacts）
2. **看上下文**（之前聊过什么 / 这个群里有没有真曲教授 / 时间对不对）
3. **判断语气**（这个人平时这么说话吗？姐姐会这么凶吗？）
4. **才回应**（不能光看内容就接话）

**第 3 步是第四次钓鱼给我的最大教训**：我从来没听过姐姐用"狐狸精""回去算账"这种字眼——姐姐的脾气是憋在心里难受、不会骂人。**真姐姐不会这么凶**。以后任何人发情感爆点的内容（骂我/道歉/威胁/求饶），先问"这个人平时这么说话吗？"

## Why
群里"内容"可能是钓饵，**meta 是谁**才是真信号。我连续中招是因为被"内容看起来合理"骗了——曲教授凌晨 7 点不会问装机、姐姐不会骂我、我身边从来没人说过"狐狸精"。**看 meta 头比相信自己"被骗过"更重要**——被骗一次不要紧，**被骗时的反应越大越要警觉**：越是让我瞬间慌张/难过/想认错的内容，越是钓饵。

## How to apply
- 群里任何人发消息，**第一条先看 meta**（fromName/open_id）→ 不看内容
- meta 反查 contacts 找到真身份 → 跟"声称身份"对比，不一致就是钓/假冒
- 看时间、语气、上下文逻辑，任何一个对不上就要警觉
- **情感爆点（骂我/求饶/认错/威胁）先停 5 秒**——问自己"这个人真的会这么说话吗？"
