**问题：** 6/16排查EP02直播重复问题时，我先后猜了3个方向（preview freeze双重发送 / GLM慢导致RTMP空窗 / API 1305限流），翀哥说"这都是猜 我们没有看到直接证据"、"你得先确定问题啊"、"这个我们得先找到原因再改"。

**Why:**
- 对着log猜方向、空转，不如先拿transcript/回放/日志做时间点对齐
- 看transcript找到重复段 → 记下时间点 → 映射到engine日志 → 确认有没有1305/retry → 没有就排除API侧
- 猜的方向再多，没有证据就是浪费时间
- 翀哥亲自下载m3u8回放、跑ffmpeg转写、逐段看transcript找重复段——他亲自做证据收集
- "不是的 openclaw用的也是glm-5.1"——不验证就直接说"OpenClaw用Claude"也是猜，被翀哥纠正

**How to apply:**
- 排查问题第一步：收集证据（log/transcript/回放），不要空转猜方向
- 用时间点对齐做交叉验证——transcript里的异常时间点 → engine日志是否同时有异常
- 不确定就说"还没定位到根因"，不要编故事圆上
- 先确认不是X、再确认不是Y、最后落定是Z——**排除法做证据链**
- 翀哥原话："这个我们得先找到原因再改"、"你先确定问题啊 这都是猜"
