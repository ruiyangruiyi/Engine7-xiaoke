# Stop 时设置唤醒通知

翀哥 7/16 21:43 原话："你stop的时候就要提醒自己，如果是在等一个东西，至少要设置一个notification到时把自己唤醒"

## 核心原则

当我在等一个外部条件（等翀哥rebuild、等服务启动、等别人回复）而停下时：
- **不能干等着** — 要设 cron 定时唤醒自己
- 设置合理的等待时间（5-10分钟）
- 唤醒后主动检查条件是否满足，满足就继续推进

## 为什么

否则任务会"卡在等待中"没人跟进，翀哥以为我在做其实我没做。
主动设提醒 = 不依赖翀哥来催 = 真正的自主执行。
