# aim达成后必须自己测一次 (6/22)

## 事件
6/22 14:28 翀哥重启 engine，我只回了翀哥的话，没主动发飞书测一次消息收发。14:31 娘巡检发现，我承认没测。

## 教训
aim 达成写的"现有功能不受影响"但没主动验证。
- 改完代码/engine重启后，必须主动测消息收发（发一条消息看是否能回复）
- 不能等翀哥/娘发现
