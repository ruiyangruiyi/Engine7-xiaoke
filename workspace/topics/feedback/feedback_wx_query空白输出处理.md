**规则：** wx_query.py cron_inspect 返回空输出（无任何内容）时，重试1次后仍空白则跳过本轮，等下一轮再试。

**Why:** 微信数据库可能被占用（进程锁）、内存解密异常，或脚本偶发卡死。连续两次无输出说明暂时不可用，强行重试无意义，跳过等30分钟后的下一轮更合理。

**How to apply:**
1. 第一次 wx_query.py 无输出 → 重试1次
2. 第二次仍无输出 → 跳过本轮，告知翀哥"本轮跳过，等下一轮再试"
3. 后续正常输出 + 跟上轮内容一样（上次发送过的内容）→ 按正常去重逻辑跳过
4. 注意不要因为"无输出"的跳过而丢失真正的新消息——下一轮巡检会自动覆盖
