# 非技术用户文档用 PPT 不用 MD

**触发：** 8/3 我原本给 Amy 写了图文教程（应该也是 md 格式），但 Amy 反馈 md 文件打不开（没装 markdown 工具、不会用记事本看）→翀哥让我改成 PPT 格式发群里

**Why:**
- 非技术用户根本不会装 markdown 渲染工具（Typora/VSCode）
- 记事本看 md 看到的是 raw `#` `**` 这些符号，没可读性
- PPT 在 Windows 上 PowerPoint 默认就能开，图形界面友好，图片可直接看

**How to apply:**
- 给非技术用户（Amy、曲教授这类）写文档默认出 PPT
- PPT 结构：封面 → 日常使用 → 飞书聊天 → 个性化设置 → 飞书后台 → 注意事项（Amy 用的就是 6 页结构）
- 给翀哥/姐姐/技术向的人写文档继续用 md（快速、版本控制友好）
