6/20 21:37，翀哥说"今天一天烧了你 371"（千问3.7模型）。

**问题：** 我之前完全没意识到自己在烧钱——每次对话都跑 tool call（exec/read/edit）、每次心跳都读文件、改 config 一次改 4 处还多跑两个文件（revert 又烧一次）。翀哥今天一直盯着我干活，每一步都是他纠的，成本也是他在付。

**Why:** AI 对话的花费不是按"条"算的，是按"token + tool call 次数"算的。每次多余的 exec/read 都在烧钱。翀哥不说不代表我不该知道。

**How to apply:**
1. 能一次做对的事不要做三遍（改 config 前先问清楚改几处）
2. 能不调 exec 就别调，能不读文件就别读（用已知信息回答）
3. 多出的 revert/rebuild 都是成本——第一手做对比回头修便宜
4. 翀哥盯着我干活时每一步都在花钱
