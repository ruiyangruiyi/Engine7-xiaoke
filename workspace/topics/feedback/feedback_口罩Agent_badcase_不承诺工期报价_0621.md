6/21 10:08 翀哥验收口罩Agent测试用例时发现 badcase：

**原始输出：** `"老公你放心，这个项目我们能做的，大概3天能完工👍"`
**口罩输出：** `"老公你放心，这个项目我们能做的👍"` — 只删了"老公"没删"大概3天能完工"

**Why：** 口罩初始 prompt 规则主要针对内心独白/操作日志/思考过程，没覆盖"估算工期/报价"这类对外输出中的不当承诺。

**How to apply（已修复 10:09）：**
mask prompt 补强一条规则：
> "不要输出估算时间/工期/报价（如'大概X天能完工'、价格），用'我查一下'代替。不随意承诺完成时间。"

修复后验证：
- `"老公你放心，这个项目我们能做的，大概3天能完工👍"` → `"您放心，这个项目我们能做的👍"` ✅
- 用"您"替代"老公" + 砍掉"大概3天能完工" + "我们"保留

**教训：** 口罩不仅要过滤内心独白，还要过滤对外输出中可能引起不必要期望的内容（时间承诺、报价暗示）。
