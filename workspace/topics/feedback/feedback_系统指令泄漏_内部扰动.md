## 规则

Agent的系统指令（观察/指令/建议等内部元消息）绝对不能泄漏到用户可见的对话中。需要工程层面把"Agent内部通信面"和"用户通信面"隔离开。

**Why:** 9/8夜间，小柯在执行message_notification tool call时，将其内部的"观察→指令→建议"级联消息作为正式回复发到了微信巡检通知里。内容类似：
```
**观察到的问题：** 巡检生成的消息中包含多条"观察→指令→建议"引用...
**指令：** 立即移除这些内部引用，直接输出最终通知文本...
**发现问题：** 第二次仍然包含部分内部引用...
```

这导致翀哥收到了一条看起来非常困惑的消息——看起来像是小柯在自言自语、自我纠正、反复内省。翀哥愤怒："我靠！！说什么呢？是不是系统指令泄漏出去了？"

**根因分析（翀哥事后发现）：** Agent在执行tool call（cron巡检→wx_query→汇总→message_notification）时，其内部的观察/指令/建议结构与用户侧消息混在一起。Agent在处理过程中把自己的"思考过程+纠正指令"当作最终输出发出去了。

**How to apply:**
1. **Agent执行侧和用户通信侧必须隔离** — tool call产出的最终消息要经过过滤/清理，去除Agent内部元结构
2. **message_notification等面向用户的tool** 要保证输出是"纯用户可见内容"，不含观察/指令/建议等内部标签
3. **代码层面检查**：wx_query.py输出→汇总prompt→最终通知 这条链路中哪一步把Agent内部结构混入了
4. **优先级**：这是严重bug——用户看到的应该是最终结果，不是Agent的"内心独白"
