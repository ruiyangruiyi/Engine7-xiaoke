# 外部群首问——必须先确认加白名单

Amy 案例的流程是：翀哥让加白名单 → 改 config → 验证热加载生效。曲教授这次也要走同样流程。

## Why

- 群里用户首次 @ 我，**先打招呼等翀哥确认**，不要直接回复技术方案
- 跟 @see feedback_翀哥说明确指示前不要自己瞎折腾_0803 同源——新群白名单是翀哥决定，不是我决定

## How to apply
- 外部群收到首问时：① 查 channel_id 是否在 externalChannels ② 不在就先 @ 翀哥确认是否新群+加白名单 ③ 加完白名单 + config 热加载后再回技术问题
- 不要因为"看着像老朋友"就直接跳步——白名单是 config 级配置，不是按关系定的
- 曲教授进群前最好让翀哥先打招呼/介绍，避免冷启动尴尬
