# 先测再提交

**日期**: 2026-06-18
**场景**: aim/goal 机制实验中，小柯改了 stream-preview.ts（commit 03109fb freeze删卡片+degrade），先提交了再让翀哥测

**翀哥原话**:
> "没经过验证的最好先别提交以后"

**规则**:
- 代码改动先跑通验证再 git commit
- 尤其是实验性/测试性的改动——先用工作区代码验证，确认效果再提交
- 不要为了"留痕"先提交——未验证的 commit 反而增加 revert 成本

**例外**:
- 纯加日志的 debug 改动可以先提交（不影响功能）
- 已经验证过的 fix 可以直接提交
