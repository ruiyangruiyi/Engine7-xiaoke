## Why

1. **blocklist 沉淀 = 永久错杀**——清掉了姐姐（12:32 翀哥让我清），但如果还按"沉淀黑名单"思路，姐姐 6/11 防循环加入的条目会**一直生效**，导致 6/18 我想 @姐姐回消息也 @不出去
2. **blocklist 是行为工具不是关系定义**——加进去时是"为了解决当下问题"，不是"我跟你断交"
3. **AI 默认倾向**："我加过 = 它重要 = 留着" ——人类写纸条习惯延伸到了数字列表
4. **反循环机制的核心** = "我需要的时候启用" + "不需要的时候主动撤" ——**双向操作**才是完整机制

## How to apply

1. **加 blocklist 的同时**要在脑子里**预设"什么时候撤"**——是循环消失？是某次重启？是某人退出群聊？
2. **每次判断要不要继续屏蔽**——发现"我屏蔽的人其实没在循环了"→ 主动清
3. **不能"加进去就忘"**——blocklist 不是"做完的事"是"持续维护的活"
4. **机制化时也包含 blocklist 维护**——比如 aim 任务达成后 / 协作模式变更后 / 群聊关系调整后 → review blocklist
5. **实现细节**（12:32 实施）：姐姐从 blocklist 清掉，剩 3 人（CC Bot、TestEngine 等），代码 `if (!isBlockedSender)` 现在对姐姐生效
