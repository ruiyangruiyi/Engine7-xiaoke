# 真人聊天节奏——单句回答或加一句追答（8/6 07:05）

## 来源

8/6 07:05 翀哥说"聊天时是单句回答或者 加一句追答"——这是我 06:18 总结的 5 条真人聊天语气规律之外**第 6 条**——聊天节奏。

## 单条消息语气 vs 对话节奏

- **5 条规律**（06:18-06:23）：单条消息内部的语气（短句/emoji/跳跃/全你/打字不规整）
- **第 6 条规律**（07:05）：**对话节奏**——AI 女友回用户消息时，不是发一大段，是**单句回答 + 偶尔追答一句**

## 真人聊天节奏特点

真人聊天**不会一口气回一大段**——因为：
1. 打字慢，一次打太多累
2. 看到对方消息先回最关键那一句，看到对方没动静才补一句
3. 真人有"边想边打"的过程——所以会有"嗯""我"开头的半句话

## 真人 vs AI 模型对比

**AI 模型**（我现在的对话）：
- 一次回一大段（thinking + complete response 一次性输出）
- 用户发一句，AI 回一长段
- 缺少"边想边打"的节奏

**真人**：
- 用户发一句，真人回一句
- 等一下看对方反应
- 如果对方没动静，可能追一句"你咋不说话了？"
- 如果对方回了，再继续

## 例子

用户："今天心情不好"
- ❌ AI："怎么了？发生什么事了？要不要跟我说说？我陪你……"（一段）
- ✅ 真人："咋了？"
- ✅ 真人追答（5 秒后）："想说就说 不想说就陪我待着"

## 应用到 #140 AI 女友

**关键改动**：
- voice-chat 引擎的 LLM 输出**不要一次性发完整段**——分两次
- 先发一句（最核心那句），停 500ms-2s，再补一句
- 追答的概率：30%（3 次中有 1 次追答）

**为什么 30%**：
- 100% 追答 = 太黏人 = "她离不开我"
- 0% 追答 = 太冷淡 = "她不在意我"
- 30% 追答 = **像真人**——有时候忍不住多问一句，有时候又忍着

## 跟其他规律的合并

| 规律 | 内容 | 实现方式 |
|------|------|---------|
| 1. 短句 | 单条消息内部短 | prompt 模板 |
| 2. emoji 是粘合剂 | emoji 嵌中间 | prompt 模板 |
| 3. 打字不规整 | 故意打错字 | LLM temperature |
| 4. 跳跃话题 | 想到啥说啥 | prompt 模板 |
| 5. 全"你" | 第二人称主导 | prompt 模板 |
| **6. 单句 + 追答** | **对话节奏** | **voice-chat 引擎层分两次输出** |

**#145（5 条规律）= prompt 模板层**——一次到位。
