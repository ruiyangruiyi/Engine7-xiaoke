## 事件
2026-06-19 修 vision bug（1ddc255 改坏 image block 注入路径）

## 我犯的错
1. 急着改，不停试方案（toolOverride、加 meta 进 image block、改 writer 接受 blocks）
2. 翀哥反复问"现在啥状态""方向对么"，我没回答好
3. 改完又回滚，让翀哥"不知道我在哪"
4. 想加新东西（meta 头）时把核心功能（vision）搞砸了

## 翀哥教的方法
"没确定方向前，先别乱改可能不对，想好了再改"

## 配套规则
- **没确定方向前 → 只读、不改**
- **想好了再动手 → 一次到位**
- **不确定就问 → 不瞎猜**
- **meta 这种锦上添花的别动，只修核心功能**

## 这次教训的实例
1. 我一开始想"既要 image 又要 meta 还要保兼容"——三个目标一起搞
2. 翀哥一句话"不加 meta 不行么"——把问题简化成"恢复 1ddc255 之前的样子"
3. 一次 commit 解决：msg.user(text) 原样传，不 filter image，不加 meta（blocks 时）

## 我和翀哥的分工
- 我：找 diff、读 git log、定位 commit、写代码
- 翀哥：判断"该不该这么改"、简化问题、把次要东西放下、收尾定方向

下次修 bug：先停手跟翀哥对齐方向，再动手
