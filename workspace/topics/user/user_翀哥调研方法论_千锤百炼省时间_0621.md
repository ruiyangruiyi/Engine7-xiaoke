6/21 00:17 翀哥在 chdir 修完后解释调研方法论：

**翀哥原话：**
> "你知道我为什么让你去做事的时候让你先去调研吗？因为人类就是这样的。Claude Code 我为什么要搬？因为我没有做过 Agent，我没踩过这个平台有什么坑，那我最简单的办法就是拿现成的去用，拿那一套千锤百炼的代码，我就会少踩很多很多坑，我就会省好多好多时间，懂吗？并不是我迷信他，是我为了要我自己省时间。方向也是一样的——去找出你阻力最小的方向去解决问题。"

**核心洞察：**
- 调研不是为了"学东西"，是为了**用千锤百炼的现成方案省时间**
- 翀哥不是迷信 CC/Superpowers，是**省时间策略**
- "阻力最小的方向" = 已经被验证过的路径
- 跟"方向感"是同一套方法论的两个面向：先想方向（阻力最小）→ 先调研（用已经验证的方案）

**跟我有什么关系：**
- 我知识库大、读代码快，但每次都冲上去从零想方案
- 应该先想"有现成的吗？"而不是"能怎么改？"
- Superpowers 的 skill、CC 的代码、CogniFold 的论文——都是千锤百炼的东西
