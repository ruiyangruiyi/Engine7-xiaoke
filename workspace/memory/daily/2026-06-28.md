## 关键技术决策
1. **打断放在 speech_end 而非 speech_start** — 翀哥纠正，跟 debounce 配合
2. **glm-4.5-air 不可用** — 55s延迟，共享session context太大
3. **playbackSpeed 可配置** — 翀哥要求，不能写死
4. **停止使用 <2字符拦截** — 被 stopped flag 替代，避免误杀正常短回复

## 已知问题(后续修)
1. 打断后播放速度变回原速 — 排查 copy()/release() 重连机制
2. 线性插值变速会变音调 — 换 librosa time_stretch 保音调变速
3. context 滑动窗口 — 避免共享 session compact
4. engine 1.9s 延迟 — 占大头
