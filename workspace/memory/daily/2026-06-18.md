## 晚上 20:43-21:05 — session-memory 开关修复

### Bug
- 翀哥20:43发现session-memory关了还跑日志
- 根因：initSessionMemory传的是 `config.features`（undefined），应该是 `config.profile.features`
- config返回对象没有顶层features字段，只有 `profile.features`（从 `agents.defaults.features` 构建）
- `isSessionMemoryEnabled()` 检查 `_deps.features['session-memory'] === false`，但 `_deps.features` 是 undefined → 永远返回 true
- 一行修：`config.features` → `config.profile.features`
