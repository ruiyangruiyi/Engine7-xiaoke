### ASR 乱码根因分析
- Docker locale 全是 POSIX/C（没设中文环境）
- SenseVoice 的 `funasr.AutoModel.generate()` **没有 language 参数**
- language 要在构造时传：`AutoModel(model=..., language="zh")`
- OAC 原版代码没传 language → SenseVoice 自动猜语言 → 在 POSIX locale 下猜歪
- 已改：docker-compose 加 `LANG=C.UTF-8 LC_ALL=C.UTF-8`，handler 加 `language="zh"`
