### ✅ Carpo Server 工作原理（源码级）

- **aliveLoop 20秒超时**：Push 注册后 20s 没收到**任何**包 → 删除 receiver

### ❌ Linux .so segfault → 编译修复（进行中）
- ~~根因：Timer 线程用到 rtc::Event → segfault~~ **错误判断，已纠正**
- Timer.cpp 是 Carpo 自己的，纯 C++11，没有 rtc::。PushSenderInner 也没有
- **真正的根因：Makefile 缺 `-DWEBRTC_POSIX`**
  - Windows vcxproj 定义 `WEBRTC_WIN`，Linux 需要 `WEBRTC_POSIX`
  - 没有这个宏，webrtc/base/event.cc 直接 `#error "Must define either WEBRTC_WIN or WEBRTC_POSIX"`
  - webrtc/base/criticalsection.cc 的 PlatformThreadId/PlatformThreadRef 没定义
  - 导致 287→175 个文件编译失败，rtc::/carpo:: 符号缺失
- **翀哥纠正**：lazy binding 是害人的，不要在残缺的 .so 上 debug segfault，要 0 undefined symbols
- **CP_PUSHER_ASYNC_MODE**：SDK 默认注释掉，跟 RTCP 无关，不要在 Makefile 加
- Windows vcxproj 有 175 个源文件（含 134 个 webrtc .cc），跟 Makefile 一致
- LiveBase.lib 只是 Windows 小工具库（port.c/str_utils.c），不是 webrtc
