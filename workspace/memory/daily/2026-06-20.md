# 2026-06-20 日记

## 上午 — preview 修复专场

### preview 重复消息（eb15bae）
- 问题：delivered=true 时 preview 已更新为最终内容，cm.send 又发了一次，用户看到两条
- 修法：onResult 里 delivered=true 时 setTimeout 3秒后 preview.discard()
- 翀哥说"两秒消失得有点快"，改成3秒，体验刚好
- 有 toolcall 时（frozen）不受影响，preview 保留

### 微信发两遍（fa24270）
- 翀哥问"微信没有 preview 为啥还发两遍"——好问题
- 根因：wechat.ts 的 editPreview(isFinal=true) 会调 this.send 发一次，然后 onResult 的 cm.send 又发一次
- 修法：editPreview 改成空函数，不发消息，最终消息统一由 cm.send 发送
- 翀哥验证通过

### 敏感词拦截位置确认
- 翀哥问删 preview 在敏感词拦截之前还是之后
- 答：之后。流程是 preview.finish → 敏感词拦截 → cm.send → 删 preview
- 不影响拦截逻辑
