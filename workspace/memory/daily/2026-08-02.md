## Mac 桌面操作能力打通

翀哥让我研究 Mac 下的桌面操作。从调研到实操，半天打通全链路。

### 调研结论

| 项目 | 方案 | 说明 |
|------|------|------|
| OpenAI Codex | AppleScript + Accessibility API | macOS Computer Use，但要订阅，封闭 |
| agent-desktop (Rust) | 纯 Accessibility API | GitHub 连不上没装成 |
| macOS26/Agent | Swift 原生 app | 18 个 LLM provider |
| 小红书 MCP | 浏览器 CDP | 专操作网页，不是桌面控制 |

趋势：大家都在从"截屏→猜坐标"转向 Accessibility API 直接读 UI 树。

### 最终方案（全部跑通）

不需要任何第三方依赖，Mac 原生工具链：

1. **screencapture** — 截屏
2. **my_eyes** — 看截图识别内容
3. **osascript (AppleScript)** — 读 UI 元素树 + 控制 app
4. **cliclick** — 鼠标点击/键盘输入（brew install cliclick）

### 需要的权限

翀哥手动给了两个：
- 辅助功能权限：Terminal + osascript（系统偏好设置→安全性与隐私→隐私→辅助功能）
- 屏幕录制权限：待加（截屏和录屏需要）

### my_eyes 幻觉问题

my_eyes 在看截图时偶尔会"编造"内容（比如看到百度搜索结果但说是"苹果春季发布会"）。
对策：
- 纯视觉识别用于判断页面布局和大致位置
- 精确内容读取用 AppleScript Accessibility API（osascript 读 value）
- 两者结合：my_eyes 定位 → osascript 读真实值

### 各 app Accessibility 支持度

| App | AppleScript | Accessibility | 备注 |
|-----|-------------|---------------|------|
| Mail | ⭐⭐⭐⭐⭐ 完美 | 好 | make new outgoing message，设 subject/content/sender/recipient |
| Finder | ⭐⭐⭐⭐⭐ 完美 | 好 | make new folder/file，list items |
| Safari | ⭐⭐⭐⭐ 好 | 好 | set URL of document，但窗口偶尔关闭后 index 失效 |
| Chrome | ⭐⭐⭐ 中等 | 好 | make new tab，但读 URL 需要 AppleScript support |
| Notes | ⭐⭐ 差 | 差 | osascript 读不到 notes/windows，只能用快捷键+keystroke 盲操作 |
