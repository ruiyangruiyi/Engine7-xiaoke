### 关键认知

1. **Object.assign 原地更新是核心**——不是换引用是改内容，所有持有引用的模块自动生效
2. **console.log ≠ engine 日志**——排查问题要加文件日志
3. **Plugin config 快照问题**——构造时存了快照，reloadConfig 刷新，但 start() 创建的 deps 需要重启重建
4. **热加载边界**：数据/配置类全支持，连接/端口/进程类不支持
